## Four Beats

1. **Name the project.** Give the CADian Pro project screen a short title before you open DWG files.
2. **Pin the live sheets.** Keep current files on the CADian Pro drawing editor and leave unused DWG aside.
3. **Stay on the tools.** Use CADian Pro drafting tools before you jump to a second editor.
4. **Check the workspace.** Read the CADian Pro CAD workspace before you archive a sheet.
5. **Close the loop.** Clear finished sheets so the next CADian Pro visit does not start with a search.

## First Questions

**Does CADian Pro replace every other program?**
No. CADian Pro sits beside the viewer, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate CADian Pro profile.

**Will CADian Pro feel heavy on an older laptop?**
No. CADian Pro is meant to stay readable during a normal drafting session.

**What should a new user try first?**
One small CADian Pro drawing today, then the same project screen tomorrow.

**Do drafting tools leave the workspace?**
No. CADian Pro drafting tools stay with the CADian Pro CAD workspace on that PC.

**Is CADian Pro only for a huge set?**
No. CADian Pro can hold a single local DWG while the rest of the PC stays off the board.

**Does the editor need a second CAD for Korean and English desks?**
No. CADian Pro drawing editor keeps that set on one project screen.

## Field Note

CADian Pro is easier to trust when the project screen stays smaller than the folder it came from. A named session shows what is active, the editor pins show what you will touch today, and the closing note tells the next person which local DWG changed.

The same loop fits a single detail, a client packet, or a PC shared by two people. Open the last CADian Pro CAD workspace, finish one edit, and leave fewer loose copies than you found.

A review should not have to guess which drawing belongs to the open screen. Keep that pair together inside CADian Pro.

## One Real Pass

Pick a local DWG set that already has a name. Open it in CADian Pro, keep only those files on the project screen, and finish one edit you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different job and leave it out of this CADian Pro CAD workspace.
